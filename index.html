SIPANDU PRIMA

Sistem Monitoring Survei Pelayanan Publik · Polda Kalimantan Tengah
PROTOTIPE · DATA CONTOH

Prototipe antarmuka, bukan sistem yang berjalan. Seluruh angka di dalamnya adalah data contoh yang disusun agar rantai perhitungannya konsisten: rekap unit menjumlah ke Polres, Polres menjumlah ke Polda. Tidak ada data nyata Polri di sini, dan tidak ada data yang tersimpan ke mana pun.

Nama pejabat sengaja ditulis sebagai [NAMA PEJABAT] dan nomor telepon disamarkan. Jangan mengisinya dengan data asli selama halaman ini dapat diakses publik.

Catatan teknis prototipe
Dibangun sebagai HTML, CSS, dan JavaScript biasa tanpa framework dan tanpa build step, agar dapat dijalankan langsung dari GitHub Pages. Satu-satunya pustaka luar adalah SheetJS, dimuat dari CDN hanya pada dua halaman input untuk membaca berkas Excel. Tidak ada backend, tidak ada basis data, dan tidak ada data yang dikirim ke mana pun — semua perubahan hilang saat halaman dimuat ulang.
Rumus yang dipakai: NRR unsur = Σ(frekuensi × bobot) ÷ n, lalu IKM = Σ(NRR × 1/9) × 25 untuk SKM dan IPAK = Σ(NRR × 1/4) × 25 untuk SPAK. Bobot skala SKM: 1→1,0 · 2→1,6 · 3→2,2 · 4→2,8 · 5→3,4 · 6→4,0. Skor SPAK: Tidak ada 4 · Ragu-ragu 2 · Ada 0.
